# AI Student Support System

An AI-based student support assistant that answers
college-related questions using regulations, syllabus,
FAQs and notices.

## Key Agent Capabilities

- Retrieval Augmented Generation (RAG)
- Tools
- Conversation Memory

## Technologies

- Python
- LangChain
- ChromaDB
- Ollama
- Qwen
- PDF documents
